# IEEE CEC 2027 — Proposed Special Session

Repository for the proposed IEEE CEC 2027 Special Session:

**Evolutionary Computation for Sustainable Transportation and Logistics (ECSTL)**

The proposal focuses on evolutionary computation methods for optimisation problems in transportation and logistics.

## Repository contents

- `index.html`: public-facing proposal website.
- `proposal.md`: proposal draft following the official IEEE CEC 2027 template.
- `prospective-papers.md`: working sheet for recruiting at least five committed papers.
- `images/`: organiser portraits used by the website.

## Preview locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Key dates

- Special Session proposal deadline: 15 November 2026
- Proposal notification: 7 December 2026
- Full paper deadline: 28 February 2027
- Paper acceptance notification: 7 April 2027
- Final paper submission deadline: 1 May 2027
- IEEE CEC 2027: 25–28 July 2027, Edinburgh, Scotland, UK

Dates should always be checked against the [official IEEE CEC 2027 website](https://ieeecec.org/2027/).
